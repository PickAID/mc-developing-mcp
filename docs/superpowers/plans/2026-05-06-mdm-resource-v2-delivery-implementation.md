# mdm-resource v2 Delivery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn sibling `mdm-sources` from a skeleton into a real curated resource package repository that MCP can install and query.

**Architecture:** Keep generated/private caches out of `mdm-sources`. Public releases contain small curated manifests and legal payloads; MCP-owned local caches remain generated on demand in the user environment.

**Tech Stack:** Node scripts, JSON Schema, SQLite payloads where useful, GitHub releases or local release artifacts.

---

## Current Status

`mdm-sources` is not deliverable today. It has schema and release scaffolding, but does not yet contain real package families, semantic validation, or enough payload to support MCP workflows beyond smoke tests.

## File Structure

- Create `docs/specs/mdm-resource-delivery-v2.md` in `SKillUpdate`: delivery bar and package family requirements.
- Create `../mdm-sources/schema/package-v2.schema.json`: public package manifest schema.
- Create `../mdm-sources/registry/packages/core-docs-required-v2.json`: first v2 manifest example.
- Modify `../mdm-sources/tools/validate.mjs`: validate v1 and v2 manifests.
- Test `../mdm-sources/tests/validate-v2.test.mjs`: validate v2 examples and reject private packages.
- Later create curated package families under `../mdm-sources/packages/`: docs, datapack, resourcepack, KubeJS, mappings, client visual.

## Public/Private Rules

- `mdm-sources` may contain only `public_release` packages.
- User modpack ProbeJS dumps, generated jar indexes, generated vanilla source, and local embeddings belong to MCP local cache, not this repo.
- Public payloads must be curated, reproducible, and legal to redistribute.
- Large generated payloads should be downloaded or generated by MCP after user consent, not stored in Git.

## Acceptance Criteria

- `mdm-sources` has at least one useful docs package and one useful datapack or resourcepack package.
- Public package validation rejects private/generated/cache packages.
- MCP can install the release manifest and select packages by v2 capability.
- Local generated caches remain owned by MCP and are not committed to `mdm-sources`.
